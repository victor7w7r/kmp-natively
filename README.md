# kmp-natively

A template with clean architecture for Compose Multiplatform with useful packages

Made with ❤️ by

![Alt text](shared/src/commonMain/composeResources/drawable/brandwhite.png?raw=true "Title")

### Install Packages and debug

``` bash
$ ./gradlew dependencies
$ ./gradlew :webApp:wasmJsBrowserDevelopmentRun --continuous
```

## Extra Packages

- arrow-kt: Functional programming library for Kotlin
- circuit: Declarative UI framework for Kotlin Multiplatform
- coil: An image loading library for Android backed by Kotlin Coroutines.
- ktorfit: A type-safe HTTP client for Kotlin Multiplatform based on Retrofit and Ktor.
- material-icons: A library that provides Material Design icons for Android and Compose Multiplatform.
- metro: A DI library for Kotlin Multiplatform that is inspired by Koin and Dagger.

### Change to blank template

``` bash
$ git clone https://github.com/victor7w7r/kmp-natively
$ cd kmp-natively
$ git checkout blank
```
